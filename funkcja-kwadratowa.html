1. Postać ogólna funkcji kwadratowej

f(x) = ax² + bx + c

Warunek konieczny: a ≠ 0 (gdyby a = 0, funkcja stałaby się liniowa).

Rozpiszmy to na konkretnym przykładzie:

f(x) = 3x² - 7x + 5
  • a = 3 (Pamiętaj: współczynnik to sama liczba stojąca przy x², nigdy z x!)
  • b = -7 (Zwróć uwagę na minus – znak należy do liczby)
  • c = 5 (Wyraz wolny)

2. Kierunek ramion paraboli

Współczynnik a decyduje o kształcie, szerokości oraz kierunku ramion paraboli:

a > 0

Ramiona w górę (uśmiechnięta parabola)

a < 0

Ramiona w dół (smutna parabola)

3. Wyróżnik funkcji kwadratowej (Δ)

Δ = b² - 4ac

Liczba miejsc zerowych oraz ich wzory w zależności od znaku delty:

Δ > 0 — Dwa miejsca zerowe
x₁ = -b - √Δ2a    oraz    x₂ = -b + √Δ2a

Wykres przecina oś OX w dwóch punktach:

a > 0

a < 0

Δ = 0 — Jedno miejsce zerowe
x₀ = -b2a

Wykres styka się z osią OX w jednym punkcie:

a > 0

a < 0

Δ < 0 — Brak miejsc zerowych

Wykres nie przecina osi OX. Brak rozwiązań w zbiorze liczb rzeczywistych.

Wykres unosi się nad osią OX lub leży całkowicie pod nią:

a > 0 (nad osią)

a < 0 (pod osią)

4. Postać kanoniczna i wierzchołek paraboli

f(x) = a(x - p)² + q
  • Wpływ nawiasu: Zauważ minusy wewnątrz nawiasu (x - p) – przy przechodzeniu ze wzoru do postaci kanonicznej zmieniamy znak współrzędnej p (np. jeśli p = 3, w nawiasie mamy (x - 3), a jeśli p = -2, mamy (x + 2)).
  • Zastosowanie: Postać kanoniczna pozwala „w ułamku sekundy” odczytać współrzędne wierzchołka paraboli W = (p, q).

Współrzędne wierzchołka W = (p, q) możemy również wyznaczyć ze wzorów:

p = -b2a    oraz    q = -Δ4a

💡 Przydatne własności (wskazówki maturalne):

Średnia miejsc zerowych: Jeśli funkcja ma dwa miejsca zerowe (Δ > 0), to współrzędna p leży dokładnie w połowie między nimi:

p = x₁ + x₂2

Wartość q jako f(p): Współrzędną q wierzchołka możesz błyskawicznie obliczyć, podstawiając współrzędną p do wzoru funkcji: q = f(p)
