2. Logarytmy

logₐ b = c  ⇔  aᶜ = b
  • Założenia: a > 0, a ≠ 1, b > 0

Własności logarytmów

Suma logarytmów

logₐ x + logₐ y = logₐ (x · y)

Różnica logarytmów

logₐ x - logₐ y = logₐ (x / y)
